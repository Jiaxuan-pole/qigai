# 今晚睡哪儿 · 三人的街头100日

轩哥、凡哥、马哥三个人在雾城街头过 100 天：排程、打工、乞讨、翻垃圾桶、买东西、刮彩票、治病、过冬，直到第 100 天按真实存活者收束。借鉴 Hobo: Tough Life 的设定，规则以本目录的策划文件为准（`01_100日版完整游戏策划与UI_v3.md`、`03_开发数据_商店物品愿望事件100日.json`、`04_AI对话与随机事件接入约定.md`、`刮刮乐玩法与票种_游戏设计参考.md`）。

## 启动（局域网可玩）

```bash
npm install          # 只装 @earendil-works/pi-ai（AI 台词用）
npm start            # 监听 0.0.0.0:8787，终端会打印局域网地址
```

同一 Wi-Fi 下的手机或电脑打开终端里打印的地址（形如 `http://192.168.x.x:8787`）即可玩。新开局须命名；局域网共用存档列表，可按存档名跨设备继续。浏览器保留本机副本，另可导出/导入 JSON。

端口被占：`PORT=8788 npm start`。

## AI 台词（可选）

人物夜话与部分事件台词由 GLM 生成，服务端调用，密钥不进网页；模型失败、超时、越权输出一律回退本地模板，不影响游戏。

- 读取顺序：进程环境变量 > 项目根 `.env` > `AI_ENV_FILE`（默认回退 `/Users/Admin/Desktop/polev3/kaelis-engine/.env`）。
- 变量：`BIGMODEL_API_KEY`（必需）、`AI_GATEWAY`（`bigmodel` 默认，anthropic 形状；或 `bigmodel-v4`）、`AI_MODEL`（默认 `glm-5.2`）、`AI_DISABLED=1` 关闭。
- 思考显式关闭（`thinking:{type:"disabled"}`），温度 0.9；提示词挂载了 kaelis-engine 的三张风格模块卡（自然去AI味、角色声线、日常生活流）与去AI味硬约束，见 `server/prompts.js`。
- 探针：`node scripts/ai-smoke.js` 真机调一次并校验契约。

## 玩法要点

- 每天 06:00–22:00 按真实小时推进。三人共用时钟、各自排程；一个人睡眠时，其他人仍可在同一小时行动。旧四段只用于店铺营业和 10/14/18/22 点的生存结算，不限制每日行动数。
- 每天正常体力上限为 100；醉意达到 2 时次日为 80。常规行动统一消耗 20；地铺睡眠每小时恢复 20，已摆放的床每小时恢复 30。跨街每边仍消耗 2 点体力且不推进时间。
- 咖啡按角色当日单独计数。便利店速溶咖啡喝满四次补 20 点当日额外行动额度，咖啡店现制单杯喝满两杯补 20 点；混饮时按速溶一提神单位、现制两单位累计，满四单位补 20。所有咖啡的实际杯数合并计算，前五杯无风险，第六杯起必须明确确认，确认后按虚构概率判定；跨日杯数和提神额度归零。
- 购物要人在店所在街区且店开门：安排「到店采买」推进后到店当场买；人已在该街区可直接买（每小时一次）。
- 「安排行动」按钮紧挨地图 M，打开独立规划窗口；窗口只显示三个人的下一件事，不把 16 小时排程表铺满页面。确认开始行动后才共同前进一小时。
- 彩票购买即锁结果，三款票面（街角即开彩/三个铃铛/好日子），自己刮开，在售票点核销一次。
- 愿望积压扣精神，连续 4 回合精神 0 进入崩溃掉健康；卫生低/不洁食物/伤口不护理夜里染病；病要诊所建计划，用品要护理时够得着。
- 濒死有救援期限（马哥首次多一回合），到期不救永久死亡；第 100 天末夜濒死先给救援尾声。
- 流浪汉玩法：翻垃圾桶、捡瓶罐卖钱、举纸板/速写乞讨、服务站免费餐、候车室过夜、熟人信任解锁订单。
- 夜间牌局：遇到马哥后可玩炸金花或德州扑克；火柴棍模式不动钱，真钱模式占全队一次博彩额度。马哥有 40% 的留强发牌机制，且无论由谁操控都生效；一局至多五手或有人输光。棋牌馆可选二十一点、炸金花或德州扑克；带入金额和每手底注可自定义，默认 10／2，必须为正整数且底注不超过带入。棋牌馆在 14:00–21:00 可确认开局；夜间 21:00 的原三人牌局设置仍保留，站前随机牌局也是独立内容。
- 城管与小混混（2026-09-17）：随机热点的一种，不阻塞推进。小混混（第 5 天起，晚间站前/老街）五种应对：给烟、给钱（会被记住、以后更常来）、说话（轩哥讲道理看精神、凡哥举相机、马哥报老陈）、跑（体力卫生小损、可能掉东西）、硬顶（打架：己方战力=体力 0.6+健康 0.4，马哥 +0.3，同街区同时段队友每人 +0.35；受伤三档：轻伤掉健康、中伤留伤口要护理、重伤再扣体力，健康归零当场濒死；输了最多被翻走 15 块或一件随身物，赢了 10 天不再来）。城管（日间/午后老街、站前、旧影院，针对摆摊/卖艺/乞讨/涂鸦/翻桶的人）四种：收拾走人（没收瓶罐纸板）、交罚款 20–40、讲理（王叔信任或人多五成免罚）、硬顶（几乎必输且当日禁摊）。第 10 天起偶发营地清场晨间节点；收音机会提前一晚预告哪条街查得严。

## 地点、自由活动与新玩法

十个街区均有独立街景：营地、老街、回收巷、站前、旧影院、服务站、河岸、咖啡街、棋牌馆和家具城。街景内可用左右键、A/D 或按钮走动，按住 Shift 加速；按 M 在街景与总览间切换。总览点选目标街区会按道路自动规划路线，每过一段街口显示黑屏街名后再进入街景；每边跨街消耗 2 点体力且不推进小时。

点击街景垃圾桶会选中翻桶行动，安排并推进后进入揭格棋盘；脏物会弄脏衣服、降低卫生，也可能找到食物、材料或简易鱼竿。点击瓶罐选中拾荒行动，收集后带到回收巷卖钱。店铺和库存现在显示物品像素图。

马哥初始有 60 点钓鱼熟练度，轩哥和凡哥从 0 练起。简易竿可捡到，普通竿与鱼饵在便利店，专业竿在五金店；河岸钓鱼先通过低概率咬钩检定，当前操控角色咬钩后处理收线 QTE，队友自动收线，判定区宽度为 40 + 0.8×熟练度。生鱼不能直接吃，须回营地用一份木炭加工，或带去老街出售。马哥连续三次空钩时每天最多一次喊“这个鱼就是欠干”跳河，体力 -5、衣服变湿，不会白送鱼。

篝火只消耗木炭：便宜木炭 6 元／4 格、每格烟尘 3；优质木炭 12 元／6 格、烟尘 1；无烟木炭 20 元／6 格、烟尘 0。木料、纸板等建造与回收材料不再当燃料。

工作小游戏只在主控实际参与工作时开启。基础收入照常结算，成功追加 0–25% 奖金，放弃或失误不扣掉基础收入；日报把队友自动收入和主控小游戏奖金分开列示。数值与真实页面流程仍待最终验收。

家具城出售基础单人床 45、舒适单人床 90、营地餐桌 35、木椅 12、旧沙发 70、储物柜 40、营灯 18、旧地毯 25。新局没有摆床、只有两张地铺床单，马哥加入后增加到三张；家具只能在家具城购买，自动快递为营地密封包裹，回营拆包后才能摆放。营地最多摆三张床；餐桌让每人每天前两次在营地成功吃饭时精神 +2。旧档原有床会迁成可摆放的 legacy 床；没有床的人会播放地铺抱怨短镜头。

营地夜账关掉后可以留下走动、切换人物、围火坐下、整理背包、聊天、打牌或回看当天已放映的短片；“结束这一晚”后才回到晨间安排。坐下、重看电影不重复发放精神或愿望收益。

## 局域网共享存档、愿望与 AI

新开局先输入共享存档名。标题页和顶栏的“存档表”展示同一局域网服务上的公共列表，另一台设备可按名字继续。服务器将进度持久保存在项目 `.saves/`，浏览器仍保留本机副本；同档并发修改会提示版本冲突，可重新载入或另存为新档。旧本机存档可在存档表命名导入，JSON 导入/导出也保留。

“AI 安排队友当前小时”只面向当前操控人物之外的 active 队友，不能改动操控者的计划。模型不可用、超时或输出无效时会降级为本地建议，不能保证每次都由 AI 作答。基础烟酒愿望与 AI 物品愿望共存，物品愿望只从允许的可购物品中生成，并按角色按日冷却。路边求助会结合路人、天气和主角情况生成观察、开场与回应；现金、食物、耐心和结果仍由规则决定，网络失败可继续用本地文本。

开场先展示轩哥、凡哥拖箱扛袋的离场画面；与马哥相遇时三人先喊出彼此名字，随即抱在一起哭，整段约 27 秒。两个过场均有 1×/1.5×/2×/3× 速度切换与跳过入口。前两章会在结伴、下雨、健康、愿望、获得鱼竿和进入第二章时给一次简短引导。人物说话有轻量像素提示音，与“声音：关/低/中/高”共用开关。
