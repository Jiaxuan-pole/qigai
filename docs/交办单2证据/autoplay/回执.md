## 文件

- `scripts/autoplay.js`：默认三策略各 200 局，写 Markdown 报告和逐局 JSON 证据。
- `scripts/autoplay/observe.js`：构造玩家可见白名单，屏蔽彩票结果、未揭示票面、事件模板字段、未知病种和未来三天之外天气。
- `scripts/autoplay/policies.js`：实现保守、均衡、赌徒三种策略；保守补足饭、休整洗漱护理，均衡工作与定期买烟，赌徒每日尝试彩票和可见牌局。
- `scripts/autoplay/runner.js`：只通过公开 API 驱动晨间、相遇、排程、购物、事件、彩票与结算；失败后合法恢复并保证终止。
- `scripts/autoplay/statistics.js`：汇总存活、现金、十日曲线、死亡、预检、停工、断供、愿望、疾病和三类日现金，生成目标差距与建议。
- `tests/autoplay.test.js`：覆盖观察层、种子、真实结算终止、统计去重、博彩顺序与报告数值。
- `docs/平衡模拟报告.md`：由默认模拟生成；`docs/交办单2证据/autoplay-runs.json` 保留逐局数据。
