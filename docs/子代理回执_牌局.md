马哥胜率（全 AI、固定种子、各 1000 手）：炸金花 43.5%、德州 42.0%（不开牌运 38.3% / 39.7%）。第一版德州 AI 弃牌门槛太高，马哥不靠牌运就 51%，把门槛从「赔率 + 性格×0.5」改为「赔率×0.9 + 性格×0.25」后修正。

浏览器实测（ego-browser，1440×900）：造第 6/7/8 天三人在营地、马哥有牌的傍晚状态，推进到夜里 → 夜账 → 「今晚打牌吗？」→ 火柴棍炸金花（操作马哥）打两手：看牌/跟注/比牌按钮按合法动作出现，AI 逐条念动作与台词，手结束亮牌型并结算；收牌总结显示各人 ±火柴与精神 51→57；日志写入「夜里打了2手炸金花……三人精神+6，熬夜体力-5」，马哥牌桌愿望部分缓解。次日晚德州同样跑通（翻前/翻牌/过牌/下注/全押按钮、公共牌与底池显示）。第一次截图发现玩家自己的牌压在公共牌区，已把玩家手牌移到头像上方并复查。

## 没做 / 疑问
- 真钱模式三人共用现金，本质是零和内部转移；只在马哥的赌瘾愿望、`gambles` 计数和当日博彩额度上有意义。若要真进出钱，需要外人上桌（路边牌局对手），不在本单范围。
- 押满、孤注一掷等线上平台加料没做。AI 不建模对手、不记牌，只有性格。
- 牌桌上的 AI 台词是本地模板，没接模型；`window.jwsnAudio` 只做可选调用，音效分叉有没有 `card_flip` 这个名字我没核。
