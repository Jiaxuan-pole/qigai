# 《今晚睡哪儿》100 日自动对局平衡模拟

生成命令：`npm run sim`
运行环境：Node v26.0.0；每策略 200 局；固定种子 1000–1199；目标天数 100；耗时 35.66 秒。

三种策略使用完全相同的种子集合。决策只接收玩家可见投影；真实状态仅由执行器调用公开引擎接口，并由统计器在结算后回顾。健康、精神与卫生曲线只统计当时 active/downed 人物，不含死者与未招募者。提前全灭局不会被当作完成 D100；检查点中位数只使用实际到达该日的样本。

策略规则：保守策略每天按存活人数补足两餐并留一份缓冲，低健康休息、低卫生洗漱、已知病情优先匹配护理，不赌博；均衡策略以工作为主、偶数日洗漱、每七天尝试在便利店买烟；赌徒策略只按每人一餐补货，马哥每天尝试买票，并在可见牌局热点出现时选择付费参与。购票受饭钱保护、营业时间与每日两次博彩额度约束，牌局没有可见机会时不会伪造事件。

日类型按“护理日 > 交付日 > 普通日”分类；护理日含成功结算的 clinic/aid/rescue/挂载护理，交付日只含 coop/trio/预约 oddjob。曲线先在每局每个检查点对当时存活或濒死人物取中位数，再跨局取中位数。

## 建议调整参数

- 保守策略三人存活率低 70 个百分点：优先核对 `rules.foodPrice` 与 `items.meal.price` 是否一致，再分别试调 `ACTIONS.kitchen.foodGain`、每格饱食扣减和每日两次进食节奏；`foodPerLivingActorPerDay` 只影响饭钱预留，不能直接缓解实际缺饭。
- 赌徒策略未高于 40% 上限，暂不建议继续削弱博彩策略。
- 护理日已有样本：若其中位数超出 −20～60，再调整诊所评估费或护理用品价格。
- 交付日没有样本，交付收益不确定；固定策略未主动抢大单，不能拿普通职业工作替代。
- 每次调整后使用相同 1000 起始种子集合复跑，比较参数前后差值。
