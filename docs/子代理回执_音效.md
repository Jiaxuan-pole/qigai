## 逐文件

- `public/ui/audio.js`（新）：纯逻辑导出 `VOLUME_STEPS/nextVolume/FILES/SYNTH/resolveSource/sceneFor`；运行时 `initAudio()`（首次 pointerdown/keydown 建 AudioContext；声音按钮四档循环存 `localStorage['jwsn.volume']`；标题/游戏页显隐用 MutationObserver 自动切场景；页面隐藏时 suspend；所有 button 点击自动出界面音）、`audioScene(state, result, stage)`（结算后白天场景；夜账后营地音乐+篝火/雨/风；有放映时按弹窗关闭顺序切电视嗡声→回篝火→白天）、`window.jwsnAudio = { play, ambient, bgm, setVolume, cycleVolume, mute, state }`。文件不可播（如 Safari 的 ogg）自动退到合成。
- `public/ui/app.js`：只插了 5 行——import；`advance()` 存档后 `audioScene(UI.state, result)`；`showNight` 后 `audioScene(..., 'night')`；放映行后 `audioScene(..., 'after-screening')`（占位，不重复触发）；标题按钮绑定处 `initAudio()`。
- `public/index.html`：顶栏「存档」与「标题」之间插一个 `#btnSound`。
- `public/style.css`：末尾追加 `#btnSound{min-width:88px}`。
- `public/audio/*`、`public/audio/CREDITS.md`：素材与署名。
- `tests/audio.test.js`（新，4 项）：档位循环、名字表完整（牌局/开场用到的名字都在、无文件者必可合成）、来源选择三分支、场景推断。

## 没做 / 已知边界

- 夜话结束后到清晨的切换靠下一次结算（或标题/游戏切换）触发；夜话没弹出时，篝火会一直放到下一次推进。
- 雨声原作非无缝循环，只用 1 秒淡入淡出掩盖接缝，没有做交叉淡化。
- 没有人工试听素材响度，各总线增益是常量（bgm .5 / ambient .6 / sfx .8）。
- 未改 README、DECISIONS。
